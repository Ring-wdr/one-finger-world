# 서사·진행 토대 디자인 (One-Finger World)

Date: 2026-05-07

## 목표

이 문서는 한 손가락 3D 액션 RPG 프로토타입(One-Finger World)이 통제된 입력 샌드박스에서 벗어나, **스토리 진행·던전 구성·레벨 디자인**을 갖춘 게임으로 자라기 위한 토대를 정의한다.

이 문서는 게임의 모든 콘텐츠를 명세하지 않는다. 이후의 모든 챕터·스테이지·시스템 기획이 따라야 할 **디자인 필러와 표준 형식**을 잡고, 그 형식이 실제로 작동하는지 보이기 위해 **챕터 1을 끝까지 구체화**한다. 시즌 1 전체 시놉시스는 이 토대 위에서 별도로 작성된다.

## 디자인 필러

8개의 핵심 결정이 이 토대를 이룬다. 이 결정은 모두 합쳐서만 일관되며, 단독으로 변경되면 다른 결정이 무너진다.

1. **형태**: 모바일형 챕터/스테이지 — 3~5분 본편 표준, 종장에 한해 ~7분.
2. **세계 톤**: 폐허가 된 신성 왕국 — 멜랑꼴리한 다크판타지, 한 줄기 희망.
3. **주인공**: 잊혀진 자 — 이름과 과거를 잃은 채 깨어나, 던전을 깨며 기억을 조각조각 회복.
4. **진행 구조**: 세계 지도 분기 — 본편 경로 + 사이드 경로. 클리어할수록 지도가 차츰 드러남.
5. **던전 형태**: 짧은 회랑 + 보스 — 분기 없는 직선/약한 코너, 단일 보스.
6. **성장 모델**: 콤보 스킬 트리 — 장비·레벨 없음. 한 손가락 조작의 깊이에 베팅.
7. **서사 전달**: 챕터 인터루드 — 정적 일러스트 + 텍스트. 다이어제틱 환경 단편으로 보강.
8. **반복·실패**: 별점 도전 + 즉시 재도전 — 사망 시 처음부터 재시작 또는 지도로 나가기 선택.

## 스테이지 해부

본편 표준 스테이지의 7비트 구조. 총 길이 3~5분(종장 ~7분).

| 비트 | 시간 | 내용 |
|---|---|---|
| 진입 | ~5초 | 페이드인, 환경 음향, 위치 텍스트 1줄 |
| 조우 1 | ~45초 | 잡몹 그룹 1~3개체, 워밍업 |
| 짧은 통로 | ~20초 | 환경 셋피스 + 룬 단편(반짝임) |
| 조우 2 | ~45초 | 더 강한 그룹 또는 미니 수호자 |
| 보스 룸 진입 | ~10초 | 조명·음악 톤 시프트 |
| 보스전 | 90~180초 | 1~2 페이즈, 콤보·회피 시험 |
| 결말 | ~15초 | 회상 단편(일러스트 1장 + 1~2줄), 보상 화면 |

설계 원칙:

- 회랑은 직선 + 약한 코너만. 분기 없음. 한 손가락 내비게이션 부담 최소화.
- 화면당 잡몹 최대 3마리. 그 이상은 한 손가락 조작이 무너지기 쉬움.
- 보스는 한 챕터의 정체성. 항상 단일. 외형과 패턴이 곧 그 챕터에서 회복되는 기억의 의인화다.
- 죽음 시 처음부터 다시 도는 것이 부담스럽지 않을 길이를 유지한다(곧 7분을 넘기지 않는다).

## 적 분류 (시즌 1 통합 어휘)

세 카테고리로 모든 적을 묶는다. 카테고리는 그대로 환경 톤을 결정한다.

- **추모자(Mourners)** — 폐허에 남은 신도의 잔재. 떼지어 나옴, 약함, 슬픈 시각. → 환경: 폐허 외곽.
- **수호자(Wardens)** — 성소를 지키도록 만들어진 구조·정령. 패턴형, 단단함. → 환경: 성소 내부.
- **기억의 화신(Memory Avatars)** — 보스 전용. 잊혀진 누군가의 형상. 챕터마다 1개체. → 환경: 봉인된 핵.

세 카테고리가 시즌 1 환경 키트의 계층(외곽 → 내부 → 핵)과 시각적으로 짝지어진다. 다만 챕터 내 적 구성은 카테고리를 섞을 수 있다 — 외곽 챕터에 작은 수호자를 끼워 입력 학습 곡선을 짜는 식이다.

## 세계 지도 + 진행

지도는 게임 시작 시 첫 노드만 보인다. 본편 클리어마다 1~2개의 새 노드가 등장한다. 본편(★) 노드는 잠금 순서가 있고, 사이드(○)는 인근 본편 클리어 시 해금되며 클리어가 강제되지 않는다.

지도가 차츰 그려지는 행위 자체가 "잊혀진 세계가 다시 형태를 갖춘다"는 메타포다. 플레이어의 진행과 주인공의 회복이 시각적으로 합치된다.

사이드 스테이지의 역할:

- 추가 스킬 포인트.
- 부가 기억 단편(선택적 서사 보강).
- 변종 잡몹 학습장.

## 콤보 스킬 트리

스테이지 클리어 보상은 스킬 포인트(SP)다. 본편 클리어 = 1 SP, 별점 1개당 +1 SP, 본편당 최대 4 SP. 사이드는 스테이지당 1 SP + 도전 보너스 1 SP, 최대 2 SP.

트리는 3개 가지로 나뉜다.

- **콤보** — 공격 슬롯 추가, 새 마무리 동작.
- **회피** — 대시 무적 프레임, 카운터 기회.
- **신성** — 신성 게이지 회복 속도, 발동기(특수기) 슬롯.

트리는 영구적이며 언제든 리셋 가능하다.

**서사적 게이팅**: 일부 본편 보스는 특정 가지의 N개 이상 노드 보유를 요구한다. 이는 "기억을 충분히 되찾아야 다음 기억 앞에 설 수 있다"는 서사적 정당성과 결합한다. 게이팅 본편은 시즌당 2~3개로 제한해 그라인드 강요로 변질되지 않게 한다.

## 서사 전달

모든 서사는 정적 일러스트 + 텍스트와 다이어제틱 환경 단편으로 전달한다. 3D 컷씬·풀 보이스·인게임 다이얼로그 박스는 사용하지 않는다.

| 채널 | 위치 | 분량 |
|---|---|---|
| 챕터 시작 인터루드 | 본편 진입 직전 | 일러스트 1~2장 + 텍스트 1~2 페이지 |
| 보스 처치 직후 회상 | 보스 사망 후 결말 비트 | 일러스트 1장 + 텍스트 1~2줄 |
| 챕터 종료 다리 | 챕터 클리어 직후 | 일러스트 1장 + 짧은 독백/환영 |
| 사이드 인터루드 | 사이드 진입 직전 | 짧은 텍스트만, 일러스트 재활용 가능 |
| 다이어제틱 환경 단편 | 스테이지 내부 | 한 줄짜리 환경 텍스트, 줍는 룬 |

**글쓰기 톤**: 멜랑꼴리, 침묵에 가까운 간결함, 직설적 설명 회피. 한 사람이 잃어버린 것을 찾아 걷는다는 음역이 모든 문장에 깔린다. 핵심 정보(이름·과거의 정체)는 시즌 종반까지 직접 노출하지 않는다.

**다이어제틱 튜토리얼**: 입력 학습은 별도의 UI 튜토리얼이 아니라 환경 텍스트로 처리한다. 예: "*너는 걸을 줄 안다.*" — 이 형식은 학습 제공과 동시에 주인공의 회복 메타포가 된다.

## 별점 도전 + 실패 처리

각 본편 스테이지에 3개의 도전 과제가 있다.

- **시간** — 일정 시간 안에 클리어.
- **피해** — 누적 피해 일정량 이하로 클리어.
- **콤보** — 보스에게 일정 콤보 이상 한 번.

사이드는 도전 1개만 (시간/피해 중 하나). 도전 별점은 영구적이다. 죽거나 나가도 이미 딴 별점은 사라지지 않는다.

**죽음 처리**: 사망 시 모달이 두 선택지를 제시한다.

- **재도전** — 스테이지 처음부터 시작. 체크포인트 없음.
- **나가기** — 지도 노드 선택 화면으로 복귀. 막힌 챕터에서 빠져나갈 출구는 항상 보장된다.

체크포인트가 없는 대신 본편 표준 길이를 3~5분으로 못 박아 처음부터 다시 도는 부담을 줄인다.

## 챕터 1 수직 슬라이스 — "첫 기도의 자리"

토대를 검증하기 위해 챕터 1을 끝까지 구체화한다. 이후 챕터들은 이 슬라이스를 템플릿으로 삼아 작성된다.

### 장소 — 무너진 외곽 사원

왕국 가장 바깥의 폐허 사원. 와르르 무너진 석조 회랑, 깨진 스테인드글라스 사이로 황금빛이 한 줄기, 흩어진 기도 구슬과 찢긴 경전 종이. 멀리 더 큰 성당의 실루엣이 안개 너머로 흐릿하게 보인다 — 앞으로 가야 할 곳을 시각적으로 약속한다.

색조: 차가운 회청 + 깨진 유리 너머의 따뜻한 황금 한 줄기.

### 서사 비트

1. **챕터 시작 인터루드**(일러스트 1장 + 텍스트 1페이지):
   "이름이 떠오르지 않는다. 손에 검 하나. 발 아래 깨진 기도. 누군가 사원 안쪽으로 걸어가는 환영 — 너와 같은 장구를 한 자."
2. **플레이 내부** — 환영을 따라 사원 안쪽으로.
3. **보스 처치 직후 회상**(일러스트 1장 + 1~2줄):
   "한 어린 신도가 처음 외운 기도. 이름이 적힌 종이 한 장. 누군가의 손이 그 이름을 부른다."
   (이름은 보이지 않음 — 미스터리 보존.)
4. **챕터 종료 다리**(일러스트 1장 + 짧은 독백):
   "환영은 다시 안쪽으로 사라졌다. 따라가야 한다."

### 스테이지 구성

| 비트 | 적/내용 | 학습 목적 |
|---|---|---|
| 진입 | 페이드인, "*이곳은 너의 자리였다.*" | 톤 셋 |
| 조우 1 | 추모자 2 (가장 약한 변종, 떼지어 느리게) | 드래그·탭 학습 |
| 짧은 통로 | 깨진 기도 구슬 더미(반짝임), 환영 잔상 | 환경 호흡 |
| 조우 2 | 추모자 3 + 작은 수호자 1 | 회피·대시 학습 |
| 보스 룸 진입 | 조명 황금 → 푸른 톤 시프트 | 임팩트 |
| 보스전 | 첫 기도의 그릇 (2페이즈, 90~120초) | 콤보 시험 |
| 결말 | 회상 컷 + 보상 화면 | 첫 SP 지급 |

### 보스 — 첫 기도의 그릇 (Vessel of the First Prayer)

부서진 기도 구슬과 찢긴 경전이 천 자락처럼 두른 인간 형상.

- **페이즈 1**: 슬픈 사도풍 근접 공격. 느리고 읽기 쉬움. 콤보 학습용.
- **페이즈 2**: 구슬을 흩뿌리는 영역 패턴 + 환영 분신. 회피·타이밍 시험.

서사 함의: "기도를 받을 자였으나 이름을 받지 못한 신도."

### 다이어제틱 튜토리얼 흐름

UI 강요 없이 환경 텍스트로 입력 학습을 분배한다.

- 첫 조우 직전: "*너는 걸을 줄 안다.*"
- 첫 조우 직후: "*너는 칠 줄 안다.*"
- 두 번째 조우 전: "*너는 피할 줄 알았다.*"
- 보스전 직전: "*잊은 손이 기억해낸다.*"

### 사이드 스테이지 — "돌아오지 않는 행렬"

사원 외곽 묘지. 추모자 무리 학습장.

- 짧은 인터루드: "그들은 자신이 어디로 향하는지 잊었다."
- 보상: SP +1, 변종 추모자 학습.
- 일러스트 1장(시작/종료 공용 재활용 가능).

### 챕터 1 별점 도전

- **시간**: 4분 이내 클리어.
- **피해**: 누적 피해 30 이하.
- **콤보**: 보스에게 8콤보 이상 한 번.

### 챕터 1 신규 자산 견적

- 일러스트: 4장 (시작 인터루드 1, 보스 회상 1, 종료 다리 1, 사이드 1).
- 환경 키트: "외곽 사원" (석재 회랑, 깨진 유리, 기도 구슬, 환영 잔상 셰이더).
- 적 모델: 추모자 1, 작은 수호자 1.
- 보스 모델: 첫 기도의 그릇 1 (2페이즈 외형 변화 포함).
- 음악: 사원 BGM 1, 보스 BGM 1, 인터루드 정적 톤 1.

## 제작 가드레일

### 시즌 1 권장 규모

- 본편 8~10 챕터, 사이드 5~8개 → 총 13~18 스테이지.
- 별점 무시 클리어 시 약 1.5~2시간, 별점 풀 시 약 4~6시간.
- 일러스트 총량 견적: 본편당 3 + 사이드당 1 ≒ 30~40장.
- 신규 보스: 8~10 + 마지막 챕터 대형 보스 1.
- 환경 키트: 4~5개. 외곽 사원 → 성소 내부 → 봉인된 핵의 계층을 따라 점진적으로 확장.

### 챕터 추가 시 따라야 할 형식

이후 챕터 기획은 모두 다음을 갖추어야 한다(챕터 1이 표준 템플릿이다).

- 단일 장소 + 색조 정의.
- 4개의 서사 비트(시작 인터루드, 플레이 내부 흐름, 보스 회상, 종료 다리).
- 7비트 스테이지 분해표.
- 단일 보스 + 2페이즈 구분 + 서사 함의.
- 다이어제틱 튜토리얼 또는 새 콤보 단계 학습 텍스트.
- 사이드 스테이지 1개 (선택, 권장).
- 3개 별점 도전.
- 신규 자산 견적.

## 범위 외 (시즌 1)

이 토대가 명시적으로 다루지 않는 항목.

- 멀티플레이·PvP.
- 풀 보이스 (환경음과 텍스트만 사용).
- 3D 컷씬 (모든 서사는 정적 일러스트 + 텍스트).
- 광범위한 콘트롤 옵션 (입력 임계값 튜닝만 노출).
